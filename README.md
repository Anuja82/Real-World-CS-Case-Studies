**Case 01 - Deadlock**
Domain: Operating System

Problem : Demonstrates how two processes can become permanently blocked while waiting for resources held by each other.

Concepts Covered:
** Multithreading
** Thread Locks
** Resource Allocation
** Deadlock
** Circular Wait

Implementation: Python (threading, time)
Expected Result: Both threads get stuck waiting for each other's resources, demonstrating a deadlock.
