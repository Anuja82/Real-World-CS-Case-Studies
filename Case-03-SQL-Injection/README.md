Case 03 - SQL Injection

Domain: Cybersecurity and Database Security

Problem
Demonstrates how attackers can manipulate SQL queries through specially crafted user input to bypass login authentication

Real-World Scenario
A banking application uses a login system to verify usernames and passwords. If SQL queries are constructed using unsafe string concatenation, an attacker may bypass authentication using SQL Injection.

Concepts Covered
** SQL Injection
** SQLite Database
** SQL Queries
** Authentication Bypass
** Database Security
** User Input Validation

Implementation
Language: Python
Database: SQLite
Libraries: Sqlite3

Learning Outcome
Understand how SQL Injection works and why secure SQL query handling is important.
