Cae 04 - Consumer Problem

Domain: Operating Systems

Problem: Demonstrates communication and synchronization between producer and consumer threads using a shared queue.

Real-World Scenario: An online shopping system receives customer orders and stores them in a queue.
Another process retrieves and processes those orders.

Concepts Covered:

** Multithreading
** Producer-Consumer Problem
** Thread Synchronization
** Queue Management
** Shared Resources
** Buffer Management

Implementation : Python

Libraries : threading, queue, time

Learning Outcome: Understand how multiple threads coordinate while sharing limited resources and
how queues help manage concurrent operations.
